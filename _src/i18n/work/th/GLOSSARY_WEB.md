# Edgelings website: Thai (th) web glossary

Register: same as the app. Polite neutral written Thai, no gendered particles (ครับ, ค่ะ), reader addressed as คุณ only where needed, no full stops, no question marks (questions end with ไหม, หรือไม่ or a question word), digits with spaces around them.

UI labels in running text: buttons and menu items from app_terms.json, and Google Play menu names, go in double quotes ("ตั้งค่า", "ลบบัญชี", "ลบโฆษณา", "กู้คืนการซื้อ"), because Thai has no capitals and many labels are plain verbs. Tab, league and tier names stay bare in lists. Headings and footer links are not quoted.
