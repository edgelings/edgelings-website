# Edgelings: glosar română (ro)

## Registru
- Adresare politicoasă cu pluralul de politețe (persoana a 2-a plural): "Jucați", "Încasați", "Aveți". "dvs." apare doar unde posesivul este necesar ("Liga dvs.", "Numele dvs.", "datele dvs.").
- Butoane: imperativ la plural de politețe ("Salvați", "Renunțați") sau substantiv ("Înapoi", "Ștergerea contului"). Excepție: butoanele de acord sunt "Accept" și "Refuz" (persoana 1, forma obișnuită în aplicațiile românești).
- Genul jucătorului nu este presupus: fără adjective sau participii care se referă la jucător ("Be the first" a devenit "Primul loc vă așteaptă"). Participiile la masculin ("Salvat", "Eliberat", "Deținut") se referă la slime sau la obiect.
- Litere cu virgulă dedesubt (ș, ț). Fără linii de pauză, fără punct și virgulă. Cratima apare doar unde o cere ortografia ("slime-uri", "V-ați", "într-unul").
- Numerale cu "de" de la 20 în sus: forma "other" este "{n} de monede", forma "few" este "{n} monede".
