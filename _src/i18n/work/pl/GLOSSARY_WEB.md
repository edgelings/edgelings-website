# Edgelings website, Polish (pl) web glossary

Register: as in the app, no Pan/Pani, no "Twój", no second person in full sentences. Body copy, FAQ, support and consent text use impersonal forms ("można", "wystarczy", "należy", "proszę + infinitive"), the studio speaks as "we" (Prosimy, Odpowiadamy). Buttons, captions and short play hints use the singular imperative (Graj, Pobierz, Odciągnij glutka). Consent buttons are first person (Akceptuję, Odrzucam). UI labels from the app stand in „” quotes, undeclined.
